## 功能说明
- 刷新时，不再消耗虚灵硬币。
- 灵铁锭不消耗。
- 在背包内正常丢弃资源不受影响。
---
## 前置依赖
- [基础框架下载 (BepInEx 6) ](https://builds.bepinex.dev/projects/bepinex_be/791/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.791%2Bb782da4.zip)
---
## 下载与安装
- [模组下载 FreeRefresh.dll](https://github.com/KuAgLan/LC2-FreeRefresh/releases/download/LC2/FreeRefresh.dll)
- 将框架解压放入游戏根目录并将下载的 DLL 文件放入 BepInEx/plugins 文件夹。
- 如果没有 BepInEx/plugins 文件夹则先安装框架后启动一次游戏。
